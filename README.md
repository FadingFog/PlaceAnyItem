# PlaceAnyItem

A Minecraft 1.7.10 mod: press **P** (configurable) while looking at a block to put the item in your hand onto that face.
Right-click takes it back, sneak + right-click or left-click rotates it.

If Draconic Evolution is installed, this mod stays inactive: Draconic Evolution already has the same feature.
